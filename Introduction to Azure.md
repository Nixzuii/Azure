# What is Microsoft Azure

Microsoft Azure is a public cloud computing platform developed by Microsoft that lets individuals, businesses and governments build, deploy, and manage applications and services through a global network of managed data centers. Instead of buying and maintaining physical servers or local hardware, users rent computing power, storage, and networking on a flexible "pay-as-you-go" basis.  

## Core service models

- **IaaS (Infrastructure as a Service)**: Here in this model we rent virtual machines, storage services and networking components from the cloud computing platforms like Azure, AWS, Google. While managing our own operating systems and applications.
