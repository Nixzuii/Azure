# What is Azure VM or Virtual Machine

Imagine I need a computer, but I don't want to buy one. So I rent a computer that sits in Microsoft’s giant building, and I control it from my own laptop over the internet. That rented computer is an Azure VM. It behaves like a real computer: it has a processor (CPU), memory (RAM), storage (disk), and an operating system (Windows or Linux). You can install software on it, run a website on it, and switch it off when you’re done. The only difference is that you never touch it physically.
